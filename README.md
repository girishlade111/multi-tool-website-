# Multi-Tool Website

A single-file, client-side multi-tool website — a collection of handy everyday utilities (calculators, converters, text tools, and more) bundled into one fast, dependency-free HTML page. Everything runs entirely in the browser; no server, no build step, no sign-in.

## Features

- Multiple useful tools in one page (e.g. unit converters, calculators, text utilities — check the file for the full set)
- 100% client-side: works offline once loaded
- Zero dependencies — one self-contained HTML file with embedded CSS and JavaScript
- Responsive layout that works on desktop and mobile

## Tech Stack

- HTML5, CSS3, vanilla JavaScript
- No frameworks, no build tools

## Quick Start

Open `index.html` in any modern browser — that's it. No installation or server required.

```bash
# Or serve locally with Python
python -m http.server 8000
# then visit http://localhost:8000
```
